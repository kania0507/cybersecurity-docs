# Ogólnie

DevSecOps to połączenie **Development (Dev)**, **Security (Sec)** i **Operations (Ops)**. Celem jest wbudowanie bezpieczeństwa w cały proces tworzenia i utrzymania oprogramowania, zamiast sprawdzania go dopiero na końcu.

Typowe obowiązki DevSecOps:

* Automatyzacja wdrożeń (CI/CD)
* Zarządzanie infrastrukturą jako kodem (IaC)
* Konfiguracja i zabezpieczanie chmury
* Skanowanie podatności aplikacji, kontenerów i infrastruktury
* Monitoring i reagowanie na incydenty
* Zarządzanie sekretami i dostępami
* Tworzenie polityk bezpieczeństwa
* Integracja narzędzi bezpieczeństwa z pipeline'ami

Najczęściej używane technologie:

* Linux
* Git
* Docker
* Kubernetes
* Terraform
* Ansible
* Jenkins / GitHub Actions / GitLab CI
* AWS / Azure / GCP
* Vault
* Trivy
* SonarQube
* OWASP
* Prometheus + Grafana
